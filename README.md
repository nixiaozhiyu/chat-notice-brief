# 聊天通知简洁版

把老师或同学发来的长消息、零散聊天记录，整理成重点清楚、可直接转发的简洁通知。

适合汇总陆续布置的作业、课程安排、材料提交和班级通知，让同学一眼看清：**谁需要做、做什么、什么时候完成、怎么提交、有哪些注意事项。**

## 能做什么

- **汇总零散消息**：把同一任务的补充要求合并，删除重复内容。
- **突出执行信息**：提取截止时间、任务内容、提交渠道、格式和文件命名要求。
- **保留范围与例外**：区分必做、选做、每人一份、每组一份及仅部分同学适用的要求。
- **处理后续更正**：明确的修改替换旧要求，仍然有效的其他条件继续保留。
- **标明不确定信息**：时间不明或要求冲突时列出待确认项，不自行补全。
- **方便群聊转发**：默认用简短标题、编号和短段落输出，方便复制到群聊。

## 使用方法

安装后，在 Codex 中输入：

```text
用 $chat-notice-brief 整理下面这些聊天消息，
生成可以直接转发给同学的简洁通知：

[粘贴老师或同学的消息]
```

可以一次粘贴多条记录。保留原消息的发送日期、发言人和前后顺序，有助于判断相对时间及后续更正。

如果要分批发送，可以先说：

> 我会分几次发，等我说“发完了”再统一整理。

也可以指定输出形式，例如“再简短一点”“只列新增要求”或“按课程分组”。

## 整理示例

### 原始消息

> 老师（2026年10月19日）：线代第二章1—5题，周五晚8点前交学习通，PDF，命名学号+姓名。第5题选做，不用打印。  
> 老师（2026年10月20日）：线代作业改到周日晚8点交，其他不变。  
> 同学：听说还要打印，是不是？

### 整理结果

```text
【线代作业通知】

截止：10月25日（周日）20:00，已更新。
内容：第二章1—4题必做，第5题选做。
提交：学习通，PDF格式，文件名为“学号+姓名”。
注意：不用打印。
```

同学的疑问不会被当成新要求；老师明确的更正会更新截止时间，同时保留其他有效条件。

## 安装到 Codex

1. 将本仓库下载或克隆到本地；下载 ZIP 时先解压。
2. 将完整的 `chat-notice-brief` 文件夹放进 Codex 技能目录：
   - 设置了 `CODEX_HOME`：放到 `$CODEX_HOME/skills/`。
   - 未设置时：放到用户目录下的 `~/.codex/skills/`。
   - Windows 默认路径示例：`C:\Users\你的用户名\.codex\skills\chat-notice-brief\`。
3. 在 Codex 新聊天中输入 `$chat-notice-brief` 并附上需要整理的消息。

请保留文件夹结构，确保 `SKILL.md` 直接位于 `chat-notice-brief` 文件夹内。安装后也可以用“把这些作业要求整理成可转发通知”等自然语言请求使用该技能。

## 仓库结构

```text
my-codex-skills/
├── README.md
└── chat-notice-brief/
    ├── SKILL.md
    └── agents/
        └── openai.yaml
```

- `SKILL.md`：技能的整理规则、输出方式和示例。
- `agents/openai.yaml`：技能在 Codex 中的显示名称、简介和默认提示。

## 信息处理原则

- 只依据提供的消息和可见上下文，不读取未提供的聊天历史。
- “明天”“本周五”等相对时间，仅在原消息发送日期明确时换算；缺少依据时标注待确认。
- 不把“建议”“尽量”“选做”改成“必须”，不新增截止时间、提交渠道或惩罚。
- 简洁以不改变原意、不遗漏执行条件为前提。
- 技能负责生成通知正文，转发由使用者自行完成。
